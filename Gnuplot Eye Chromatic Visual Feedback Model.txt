# Via the gnuplot application, this script plots a series of graphs illustrating the characteristics of a hypothesised eye visual 
# feedback emmetropisation mechanism that exploits longitudinal chromatic aberration to regulate eye axial length, highlighting how 
# this mechanism may be involved in the onset and development of axial myopia from near work. 

# This script accompanies the 2026 study authored by G.A.Olmi entitled "A Software Model of Chromatic Aberration Visual Feedback in the 
# Eye: Exploring the Role of Near Work in Myopia Development". This script plots the graphs presented in the study.

# This script implements the Yves Le Grand Full Theoretical Eye schematic eye model, which has been extended in the script to operate  
# at all visible light wavelengths, and for all states of accommodation. Using this schematic eye, this script then implements the 
# hypothesised chromatic emmetropisation model based on longitudinal chromatic aberration.

# In this chromatic emmetropisation model, a visual feedback signal is calculated by subtracting the level of defocus of red 
# wavelengths (gauged by the red blur circle diameter R) on the schematic eye retina from the level of defocus of blue wavelengths 
# (gauged by the blue blur circle diameter B) using the formula B-R. In this model, we hypothesise that when the B-R signal becomes 
# negative for a sustained period, it induces eye axial growth; whereas if B-R assumes a high positive value, it halts eye growth; and 
# when B-R takes on a low positive value, it has no direct effect on axial growth, but permits natural developmental eye growth. This 
# three-state chromatic scheme we posited on the basis of the features of the graph of Figure 2, a graph which illustrates how the B-R
# visual feedback signal may serve to regulate eye axial length to achieve emmetropisation. Then the graph of Figure 6 demonstrates 
# how sustained near work might result in myopia, as it shows that at close viewing distances, the B-R visual feedback signal becomes
# negative in the schematic eyes of some individuals, and our model postulates that such sustained negative B-R signals induce eye 
# axial growth, leading to axial myopia.

# (in contact as a doublet lens). The lenses can be made of different materials. The lens materials are set in the section entitled

# required, its dioptre power can be set in powerCor1, setting powerCor2 to zero.

# Where applicable, set peripheral = 0 to plot the graph for the posterior pole visual feedback signal (the visual feedback signal

# Where applicable, objectDistance specifies the distance to the viewed object (in metres) for the schematic eye. Note that we use the

# Set pupilDiameter to specify the schematic eye pupil diameter (in metres). For example 0.003 metres = 3 mm. Human pupil size varies
# from 2 to 4 mm in bright light, and 4 to 8 mm in dim light.

# Set vertexDistance to specify the axial distance in metres from the corrective lens to the apex of the front surface of the cornea in

# zero. 

# Setting blueBlurCircleAddition = 0.000055 metres (which is 0.055 mm) adds this length to the diameter of the calculated blue blur

# distance in which the blue channel has been slightly blurred to such a degree that blue points in the image expand to blur disks of 
# 1 mm diameter. Normally blueBlurCircleAddition should be set to zero. It is only used to simulate video screen blue channel blur.

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# Plastics dispersion formulas. These formulas are valid for wavelengths w from 436.8 nm to 1052 nm.
# PMMA = polymethyl methacrylate  |  Zeonex E48R = cyclo-olefin polymer. 
# Source: https://refractiveindex.info/?shelf=3d&book=plastics
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

refractiveIndexPMMA(w)               = sqrt(1 + (1.1819 * (w/1000.0)**2) / ((w/1000.0)**2 - 0.011313))
refractiveIndexZeonexE48R(w)         = sqrt(1 + (1.2969 * (w/1000.0)**2) / ((w/1000.0)**2 - 0.011721))
refractiveIndexPolycarbonate(w)      = sqrt(1 + (1.4182 * (w/1000.0)**2) / ((w/1000.0)**2 - 0.021304))



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# Plastics dispersion formulas. These Cauchy formulas are calculated by obtaining the lens material nd refractive index and Vd Abbe  
# values given here: https://www.abdo.org.uk/wp-content/uploads/2012/06/CET139.pdf and then deriving the Cauchy formulas using the  
# curve fitting tool here: https://ian-macmillan.com/Cauchy-Optical-Dispersion-Calculator/

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

refractiveIndexCR39(w)               = 1.484983 + (4.494482 * 10**-3) / (w/1000.0)**2 - (3.785738 * 10**-16) / (w/1000.0)**4

# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»

# In this section we set up functions which return the refractive index of the various ocular media in the Le Grand schematic eye 
# model for any arbitrary light wavelength w in nanometres.

# Le Grand provides the following table of refractive index values for the optical media of his schematic eye on page 9 of his book:    
# Yves Le Grand. "Form and Space Vision". Bloomington: Indiana University Press; 1967. 

# Refractive Index Values for Le Grand Eye 
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~      ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~
#                                  Colour:      Infrared          Red               Yellow            Blue              Violet
#                         Fraunhofer Line:      Oxygen A          Hydrogen C        Sodium D          Hydrogen F        Calcium G
#                              Wavelength:      759.4 nm          656.3 nm          589.3 nm          486.1 nm          430.8 nm
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~      ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~

# Air                                           1.0003            1.0003            1.0003            1.0003            1.0003
# Cornea                                        1.3726            1.3751            1.3771            1.3818            1.3857
# Aqueous Humour                                1.3331            1.3354            1.3374            1.3418            1.3454
# Crystalline Lens (relaxed at infinity)        1.4144            1.4175            1.4200            1.4259            1.4307
# Vitreous Humour                               1.3317            1.3341            1.3360            1.3404            1.3440
# Crystalline Lens (focused at near point)                                          1.4270  


# The figure for the crystalline lens refractive index at the near point of accommodation comes from the book: Günter Wyszecki, Walter  
# Stanley Stiles. "Color Science Concepts and Methods, Quantitative Data and Formulas". Wiley; 1967. The same figure can also be found  
# on page 65 of the book: Yves Le Grand and Sami El Hage. "Physiological Optics". Springer-Verlag; 1980.

# We use curve fitting to derive functions that give these eye optical media refractive index values at any arbitrary wavelength. For
# the curve fitting, we use the Cornu dispersion formula employed by Le Grand, which is of the form: N(w) = Ninf + K / (w - c), 
# where Ninf, K and c are constants, and w is the wavelength.

# To perform Cornu formula curve fitting within gnuplot, create a space-separated file called say refractive.txt, this file having two
# data columns: wavelength and refractive index. Then type the gnuplot command: f(x) = A + B/(x-C) which represents the Cornu formula, 
# followed by the curve fitting command: fit f(x) "refractive.txt" using 1:2 via A, B, C  

# Thus via curve fitting we arrive at the following six functions which return the refractive index for each ocular medium at the   
# specified visible wavelength w (in nanometres):

# ~~~~~~~~~~~~~~~~~~        ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# Material                  Refractive Index at Wavelength w (in nanometres)
# ~~~~~~~~~~~~~~~~~~        ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

airN(w)                =    1.0003                                             # Air
corneaN(w)             =    1.36033 + 7.86934 / (w - 120.302)                  # Cornea of Eye
aqueousN(w)            =    1.32102 + 7.88955 / (w - 106.973)                  # Aqueous Humour
crystallineNin(w)      =    1.39891 + 9.98421 / (w - 116.554)                  # Crystalline Lens (focused at infinity)
crystallineNnp(w)      =   (1.39891 + 9.98421 / (w - 116.554)) * 1.427/1.42    # Crystalline Lens (focused at near point)
vitreousN(w)           =    1.31956 + 7.98869 / (w - 103.558)                  # Vitreous Humour
   

# Note that Le Grand provides refractive index values for the crystalline lens in its relaxed state at five different wavelengths (as
# shown in the above table), but for the crystalline lens at the near point of accommodation, he only gives one refractive index value, 
# at the 589.3 nm wavelength. So we use calculated estimates for the near point refractive index value at other wavelengths. These 
# estimates are obtained by multiplying the relaxed crystalline lens values by the factor 1.427/1.42, which is the ratio of the near 
# point and relaxed refractive index values at 589.3 nm. This multiplication is performed within the above function crystallineNnp(w). 
 

# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»
# LE GRAND FULL THEORETICAL EYE: Radius of curvature and relative position (in metres) of the schematic eye's optical surfaces.

# In this section, we set up constants and functions that give the radius of curvature and relative position of the optical surfaces
# in the Le Grand schematic eye model. The functions take the argument fp, which is the focusing parameter detailed below. We also 
# define a crystalline lens refractive index function which has the arguments fp and w.

# The following data for the Le Grand Full Theoretical Eye model is taken from page 210 of the book: Günter Wyszecki, Walter Stanley 
# Stiles. "Color Science Concepts and Methods, Quantitative Data and Formulas". Wiley; 1967. The same data can also be found on page 
# 65 of the book: Yves Le Grand and Sami El Hage. "Physiological Optics". Springer-Verlag; 1980.

# In the Yves Le Grand Full Theoretical Eye model, the following three values remain constant at all times:

corneaRadiusFront  =  0.0078             # All values given in metres
corneaRadiusRear   =  0.0065
corneaThickness    =  0.00055


# In the Le Grand eye model, there are five variables that depend on whether eye accommodation is relaxed or focused at the near point
# of accommodation. These five variables are: 

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~       ~~~~~~~~~~~~~~~~       ~~~~~~~~~~~~~~~~
# Le Grand Eye Model Parameter           Relaxed Value          Near Point Value
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~       ~~~~~~~~~~~~~~~~       ~~~~~~~~~~~~~~~~
# Crystalline Lens Radius Front          0.0102                 0.0060
# Crystalline Lens Radius Rear          -0.0060                -0.0055
# Cornea to Crystalline Distance         0.00305                0.00265
# Crystalline Lens Thickness             0.0040                 0.0045
# Crystalline Refractive Index           1.42                   1.427    (these two refractive indices at sodium D-line 589.3 nm)

# Le Grand only provides values for these five variables at these two extremes of eye accommodation (relaxed and the near point of
# accommodation). To calculate the values of these variables for intermediate states of accommodation, we use a linear accommodation 
# formula which states that for an eye model parameter X that varies with eye accommodation, if Xi is its specified value with the eye 
# relaxed and focused on infinity, and Xn is its stated value when the eye model is focused at the near point of accommodation, then  
# the value of X at any intermediate eye accommodation is given by the formula:
#
# X  =  Xi * (1-fp) + Xn * fp, 
#
# where the focusing parameter fp runs from 0 to 1. For the relaxed eye fp = 0. For the eye accommodated at the near point fp = 1. 
#
# The University of Tübingen eye research group has employed such a linear accommodation formula for use with eye models. See: 
# https://web.archive.org/web/20160305040243/http://www.arkiv.certec.lth.se/doc/widesight/pettersson.html 

# Using this linear accommodation formula, below we set up the five linear accommodation functions for the five variables of the Le 
# Grand schematic eye model: 

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~                  ~~~~~~~~~~~~~~~~         ~~~~~~~~~~~~~~~~
# Le Grand Eye Model Parameter                      Relaxed Value            Near Point Value        
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~                  ~~~~~~~~~~~~~~~~         ~~~~~~~~~~~~~~~~

crystallineRadiusFront(fp)        =                 0.0102  * (1-fp)    +    0.0060  * fp
crystallineRadiusRear(fp)         =                -0.0060  * (1-fp)    +   -0.0055  * fp
corneaToCrystallineDistance(fp)   =                 0.00305 * (1-fp)    +    0.00265 * fp
crystallineThickness(fp)          =                 0.0040  * (1-fp)    +    0.0045  * fp
crystallineN(fp, w)               =      crystallineNin(w)  * (1-fp)    +    crystallineNnp(w) * fp    # Crystalline lens refract index


# As we vary the focusing parameter fp from 0 to 1, these five functions vary linearly, resulting in incremental changes in the eye 
# model focus. As fp runs from 0 to 1, accommodation increases from the relaxed eye state (fp=0) to the fully accommodated eye (fp=1).


# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»

# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»

# In this section, we encode lag of accommodation data, empirically measured for ten people by Alexandre Ivanoff, into ten functions by 
# means of curve fitting. The ten functions are named focusWavelength_01(fp), focusWavelength_02(fp), etc, one function for each 
# person. These functions return the wavelength the person brings into focus on their retina for any specified degree of accommodation.
# These ten functions allow our Le Grand eye to simulate the lag of accommodation characteristics of any of the ten Ivanoff subjects.

# The Ivanoff lag of accommodation data is provided as a graph on page 46 of Yves Le Grand's 1967 book "Form and Space Vision". This  
# graph displays ten curves, one for each person, indicating the wavelength in focus on the retina at different levels of accommodative 
# demand, namely 0, 0.5, 1, 1.5, 2 and 2.5 dioptres, which correspond to object distances of infinity, 2, 1, 0.667, 0.5 and 0.4 metres 
# (accommodative demand is the reciprocal of the object distance in metres). The Ivanoff accommodative lag data was extracted from the
# graph, and is tabulated in the table below.

# When curve fitting this accommodative lag data into ten functions, instead of expressing the wavelength in focus on the retina as a  
# function of accommodative demand, we express it as a function of the focusing parameter fp, as this enables us to utilise the  
# accommodative lag functions within our Le Grand eye model. The wavelength in focus was expressed as a function of fp using the 
# following approach:

# In the table below, when focusing on an object at 0.4 metres distance, we see that person 1 brings a wavelength of 495 nm into focus  
# on their retina. For the Le Grand schematic eye, we can calculate the value of fp that will bring this wavelength into focus on the  
# schematic retina when the object distance is 0.4 metres. This value of fp is 0.2873, calculated using the autoFocus() function in the  
# way described below. So the wavelength 495 nm becomes associated with fp = 0.2873 as a data point. We repeat this process for all six  
# object distances that person 1 views, in order to create the six data points of wavelength and fp value, as shown in the table column 
# 'Person 01'. We then perform a curve fit on these six data points, to create the function focusWavelength_01(fp). This function tells
# us what wavelength the Le Grand schematic eye should bring into focus on the schematic retina when the degree of accommodation is fp, 
# thereby allowing the Le Grand eye to simulate the lag of accommodation characteristics of a real person, person 1 in this case. We   
# repeat this process for all ten Ivanoff subjects in the table, so that the Le Grand schematic eye can then simulate the lag of 
# accommodation characteristics of any of the ten Ivanoff subjects.

# The Ivanoff lag of accommodation graph was obtained from page 46 of the book: Yves Le Grand. "Form and Space Vision". Bloomington: 
# Indiana University Press; 1967. This Ivanoff data is originally from the book: Alexandre Ivanoff. "Les Aberrations de l’Oeil, Leur 
# Rôle Dans L’accommodation". Éditions de la Revue d’optique théorique et instrumentale; 1953.

# was extracted from a scanned  digital image of the Ivanoff graph using https://plotdigitizer.com/app

# The first column of the above table gives the object distance (in metres) of the stimulus shown to the ten Ivanoff subjects. The 
# second column shows the accommodative demand (in dioptres) of that stimulus. The columns labelled 'Person 01' to 'Person 10' contain 
# the wavelength each subject brings into focus on their retina when viewing the stimulus at the specified object distance. To the 
# immediate right of the wavelength value is the calculated fp value needed to get the Le Grand eye model to focus that wavelength onto
# its schematic retina for the given object distance. The value of fp is always 0.0000 for objects at infinity, as here we are using an 
# emmetropic Le Grand eye.

# The fp values in the above table are calculated using fp = autoFocus(objectDistance, w, emmetropicAxialLength, 0.5, 0.5), with 
# objectDistance set to the object distance in the first column, w set to the wavelength in focus for that person at the given object
# distance, and the emmetropicAxialLength set to the person's equivalent Le Grand eye emmetropic axial length, which is given in the 
# table in metres. The function autoFocus() is defined later in this script.

# When we set up the Le Grand eye model to simulate the lag of accommodation characteristics of a real person from the Ivanoff data, we 
# want the emmetropic axial length of the model to reflect the axial length of that person. The eye axial lengths for the Ivanoff  
# subjects are not known, but from the Ivanoff data, we know the wavelength in focus on the person's retina when their eye is in a  
# relaxed state and gazing at infinity. Thus, when the Le Grand schematic eye model is in a relaxed state (that is, when fp = 0), we  
# want the model to focus that relaxed wavelength onto the schematic retina. So we set the emmetropic axial length of the eye model
# accordingly. The way we calculate the Le Grand eye model emmetropic axial length for each Ivanoff subject is detailed below in the
# comments for the function emmetropicAxialLength().

# The ten lag of accommodation functions focusWavelength_01(fp), focusWavelength_02(fp), etc, were derived using the "exponential" 
# curve fit at https://curve.fit on the 6 data points provided for each of the ten people in the above table (each data point 
# comprising wavelength in focus and fp value). The "exponential" curve fit is of the form y = a * exp(bx) + c, where a, b and c are 
# constants to be found. At https://curve.fit, the fp value is placed in the x column, and the wavelength in focus value is placed in 
# the y column. In the δy column, the δy uncertainty for the fp = 0 data points is set to 0.0001, to ensure the resulting exponential 
# equation from the curve fit passes exactly through this data point (so when fp = 0, the ten lag of accommodation functions return the 
# exact wavelength in focus in the relaxed eye state when gazing at infinity (for example, 726 nm for person 1). For other values of 
# fp, δy is set to 2.

# Note: the person 2 exponential curve was a bit wayward after curve fitting, with the wavelength in focus being unrealistically low
# (at around 300 nm) when fp = 1. So to constrain the curve to physiologically plausible wavelengths, we add an extra synthetic data  
# point to the curve fitting, which is the point: wavelength = 420 nm when fp = 0.3.

# In the table above, we give the dioptric lag of accommodation for the schematic eyes of each Ivanoff subject when the eye is viewing 
# an object at a distance of 0.4 metres. Person 2 has the highest lag of accommodation at 1.61 dioptres. Person 6 has the lowest lag at  
# 0.63 dioptres. This dioptric lag given in the table is calculated as follows:

# When an Ivanoff subject is viewing an object 0.4 metres away, due to lag of accommodation, they will bring bluer wavelengths from 
# the image into focus on their retina. The table above gives the fp value that focuses this bluer wavelength onto the retina of the 
# schematic eye of that subject for an object distance of 0.4 metres (an accommodative demand of 2.5 dioptres). And the table gives the 
# red wavelength w focused on the retina in the relaxed eye when the object is at infinity. We insert these values of fp and w into the 
# equation: eyeImageDist(objectDistance, w, fp) = emmetropicAxialLength(0), and then manually adjust the value of objectDistance in the 
# equation until the value of the left side of the equation matches the right. Once we have found the correct objectDistance via manual 
# tweaking, we divide it into 1, in order to get the accommodative demand that brings the red wavelength into focus on the retina when 
# the schematic eye accommodation is set by the fp value we specified. Then by subtracting this accommodative demand from 2.5 dioptres, 
# we get the accommodative lag in dioptres when the Ivanoff subject's schematic eye is viewing an object at 0.4 metres.


# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

focusWavelength_05(fp) = 1.439e+02 * exp(-1.551e+01 * fp) + 5.411e+02

focusWavelength_06(fp) = 1.318e+02 * exp(-1.236e+01 * fp) + 5.472e+02
focusWavelength_07(fp) = 1.804e+02 * exp(-1.367e+01 * fp) + 4.926e+02
focusWavelength_08(fp) = 1.377e+02 * exp(-1.103e+01 * fp) + 5.283e+02
focusWavelength_09(fp) = 1.859e+02 * exp(-1.298e+01 * fp) + 4.701e+02
focusWavelength_10(fp) = 1.998e+02 * exp(-5.203e+00 * fp) + 4.422e+02

# PARAXIAL APPROXIMATION GEOMETRIC OPTICS FUNCTIONS
# The following functions are based on the paraxial refraction equation and the thin lens equation.
# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# thinLensImageDist(P, objectDistance)                 Thin lens equation 
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# For an optical system comprising a thin lens of dioptre power P, and an object located at a distance of objectDistance metres from the lens, this 
# function returns the image distance from the lens (positive values of image distance indicate a real image to the right of the lens; 
# negative values indicate a virtual image to the left of the lens). We assume that the lens material is surrounded by air.

# The calculation of image distance is based on the thin lens equation  P  =  1/f  =  1/o + 1/i  (aka the Gaussian lens formula).

thinLensImageDist(P, objectDistance) =  ( P - 1.0/objectDistance == 0 )  ?  1e90  :  1.0 / ( P - 1/objectDistance )  

# The above ==?: ternary conditional operator used to prevent division by zero.



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# surfaceImageDist(R, N1, N2, objectDistance)          Paraxial refraction equation  
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ 
# For a point of light at a distance objectDistance to the left of a spherical surface of radius R (R is positive for a convex surface, 
# as viewed from the left side), where the media have refractive indices N1 to the left of the surface and N2 to the right, this 
# function returns the distance of the image from this surface (positive image distance values imply real images to the right of the 
# surface).

# The calculation is based on the paraxial refraction equation N1/o + N2/i = (N2-N1)/R, which calculates the refraction at a spherical 
# surface under the paraxial approximation (derives from Snell's law at small angles). Also called the Gaussian refraction formula.
# Rearranging, we get i = N2/( (N2-N1)/R - N1/o )

surfaceImageDist(R, N1, N2, objectDistance)  =  ( 1.0 *(N2-N1)/R - N1/objectDistance == 0 )  ?  1e90  :  1.0 * N2 / ( (N2-N1)/R  -  N1/objectDistance ) 

# The ==?: ternary conditional operator used to prevent division by zero. When the image is at infinity, this function returns 1e90.



# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»
# CORRECTIVE LENS FUNCTIONS
# The following functions relate to ophthalmic corrective lenses, and are based on the lensmaker's equation and the thin lens equation.
# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# correctiveN1(w) and correctiveN2(w) set the refractive index dispersion formula for the optical material used in the ophthalmic 
# corrective lenses placed in front of the schematic eye. Up to two lenses can be placed in front of the schematic eye in contact with 
# each other (as a doublet lens), at a distance of vertexDistance from the apex of the front corneal surface. 
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

# Set material of corrective lenses 

correctiveN1(w) = refractiveIndexCR39(w)            # The corrective lens farthest from cornea (1st lens the light passes through)
correctiveN2(w) = refractiveIndexPolycarbonate(w)   # The corrective lens closest to the cornea (2nd lens the light passes through)



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# correctiveLensPower(powerCor, w)                     Lensmaker's equation
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# For a lens of dioptre power powerCor at the standardWavelength, this function returns the power of the lens for the wavelength w (in
# nanometres). The dispersion formula for the optical material of the lens is set up in correctiveN1(w) and correctiveN2(w).

# Lens power calculations are based on the lensmaker's equation which, for a thin lens material of refractive index N placed in a 
# surrounding medium of air, is of the form: Power = (N - Nair) * ( 1/R1 - 1/R2 ). For a given power, the radii of curvature R1 and R2 
# of a lens are constant, so we have: Power / (N - Nair) = constant for all wavelengths.

# So if Ps and Ns are the power and refractive index of the lens at the standard wavelength, and Pc and Nc the same at wavelength w, 
# we have Ps / (Ns - Nair) = Pc / (Nc - Nair). Thus rearranging we have Pc = Ps * (Nc - Nair) / (Ns - Nair).

# Up to two corrective lenses can be placed in contact in front of the eye (as a doublet lens) at vertexDistance from the apex of the 
# front corneal surface, so we define two functions for these:

correctiveLens1Power(powerCor, w) = powerCor * (correctiveN1(w) - airN(w)) / (correctiveN1(standardWavelength) - airN(standardWavelength))
correctiveLens2Power(powerCor, w) = powerCor * (correctiveN2(w) - airN(w)) / (correctiveN2(standardWavelength) - airN(standardWavelength))



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# correctiveLensImageDist(powerCor, w, objectDistance)
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# For a corrective lens having a dioptre power of powerCor at the standardWavelength, this function returns the image distance for the 
# wavelength w, when the object is objectDistance away.

# Up to two corrective lenses can be placed in front of the model eye (at vertexDistance away), so we define two functions for these:

correctiveLens1ImageDist(powerCor, w, objectDistance) = thinLensImageDist(correctiveLens1Power(powerCor,w), objectDistance)
correctiveLens2ImageDist(powerCor, w, objectDistance) = thinLensImageDist(correctiveLens2Power(powerCor,w), objectDistance)

# EYE IMAGE FOCUSING FUNCTIONS
# The following functions involve our Le Grand schematic eye model focusing light rays.
# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# eyeImageDist(objectDistance, w, fp)
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# This function returns the image distance (in metres) for the light wavelength w (in nanometres) when the Le Grand eye model views a 
# point object at objectDistance away (in metres), with the degree of eye accommodation set by fp. 

# The eyeImageDist() function implements the Le Grand Full theoretical Eye model, employing paraxial approximation geometric optics to 
# calculate the image distance.

# fp = 0 sets the Le Grand eye to relaxed accommodation, fp = 1 sets the eye to the near point of accommodation. The focusing parameter
# fp can be set anywhere in the range from 0 to 1 to achieve intermediate levels of accommodation.

# objectDistance is the distance (in metres) from the object to the apex of the front corneal surface of the eye. The image distance is 
# the axial distance (in metres) from the apex of the front corneal surface to the point where the image is focused by the eye model. 

# In this chain calculation, the image distance output from the current eye surface being processed is added to the distance to the 
# next eye surface, and that value becomes the object distance input into the next surface. The image distance value of the current 
# eye surface is the virtual object distance for the next surface, so we need to place a minus sign in front of this value to indicate
# it is virtual.

eyeImageDist(objectDistance, w, fp) =                                                                                                \
                                                  corneaThickness  +  corneaToCrystallineDistance(fp)  +  crystallineThickness(fp) + \
    surfaceImageDist(crystallineRadiusRear(fp),   crystallineN(fp,w),  vitreousN(w),          crystallineThickness(fp) -             \
    surfaceImageDist(crystallineRadiusFront(fp),  aqueousN(w),         crystallineN(fp,w),    corneaToCrystallineDistance(fp) -      \
    surfaceImageDist(corneaRadiusRear,            corneaN(w),          aqueousN(w),           corneaThickness -                      \
    surfaceImageDist(corneaRadiusFront,           airN(w),             corneaN(w),            objectDistance)))) 
 


# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# eyeImageDistSingleCorLens(objectDistance, powerCor, w, fp)
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# As above, but includes a single corrective lens located at vertexDistance from the apex of the front surface of the cornea:

eyeImageDistSingleCorLens(objectDistance, powerCor, w, fp) =                                                                         \
                                                  corneaThickness  +  corneaToCrystallineDistance(fp)  +  crystallineThickness(fp) + \
    surfaceImageDist(crystallineRadiusRear(fp),   crystallineN(fp,w),  vitreousN(w),          crystallineThickness(fp) -             \
    surfaceImageDist(crystallineRadiusFront(fp),  aqueousN(w),         crystallineN(fp,w),    corneaToCrystallineDistance(fp) -      \
    surfaceImageDist(corneaRadiusRear,            corneaN(w),          aqueousN(w),           corneaThickness -                      \
    surfaceImageDist(corneaRadiusFront,           airN(w),             corneaN(w),            vertexDistance -                       \
    correctiveLens1ImageDist(powerCor, w,                                                     objectDistance - vertexDistance))))) 

# In eyeImageDistSingleCorLens(), the object distance is still measured from the apex of the front of corneal surface, not from the
# corrective lens.



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# eyeImageDistCorLens(objectDistance, powerCor1, powerCor2, w, fp)
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# As above, but includes two corrective lenses in contact (as a doublet lens) located at vertexDistance from the apex of the front 
# surface of the cornea. The power (at the standard wavelength) of the first corrective lens that light from the object passes through  
# is powerCor1, and the power of the second corrective lens is powerCor2. If only one corrective lens is required, this can be set in
# powerCor1, setting powerCor2 to 0. 

eyeImageDistCorLens(objectDistance, powerCor1, powerCor2, w, fp) =                                                                   \
                                                  corneaThickness  +  corneaToCrystallineDistance(fp)  +  crystallineThickness(fp) + \
    surfaceImageDist(crystallineRadiusRear(fp),   crystallineN(fp,w),  vitreousN(w),          crystallineThickness(fp) -             \
    surfaceImageDist(crystallineRadiusFront(fp),  aqueousN(w),         crystallineN(fp,w),    corneaToCrystallineDistance(fp) -      \
    surfaceImageDist(corneaRadiusRear,            corneaN(w),          aqueousN(w),           corneaThickness -                      \
    surfaceImageDist(corneaRadiusFront,           airN(w),             corneaN(w),            vertexDistance -                       \
    correctiveLens2ImageDist(powerCor2, w,                                                    0 -                                    \
    correctiveLens1ImageDist(powerCor1, w,                                                    objectDistance - vertexDistance)))))) 

# In eyeImageDistCorLens(), the object distance is still measured from the apex of the front of corneal surface, not from the 
# corrective lens.



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# emsleyEyeImageDist(objectDistance, w, fp) 
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# This is an adapted version of the Emsley reduced eye, in which the dioptre power of its single spherical surface is varied in order
# to simulate accommodation. We use the focusing parameter fp to adjust the radius of curvature (and thus the power) of the Emsley eye
# surface in order to achieve accommodation. We have matched the focusing power of the Emsley eye to that of the Le Grand eye.

emsleyEyeImageDist(objectDistance, w, fp) = surfaceImageDist(0.006047249 - fp * 0.000652112, airN(w), waterN(w), objectDistance)

# To match the focusing power of the Emsley eye to the Le Grand eye at both the relaxed (fp = 0) and accommodated (fp = 1) states, we 
# first place the object at infinity, and adjust the Emsley eye surface radius of curvature so that this eye model has the same focal 
# length as the Le Grand eye in its relaxed state, at the standard wavelength of 587.56 nm. We then set the object distance to 0.2 
# metres, and we adjust the radius of curvature of the Emsley eye surface so that its image distance is the same as the image distance 
# for this object in the fully accommodated Le Grand eye. So now we know the two Emsley eye surface radius of curvatures that can
# match the Le Grand eye in its relaxed and fully accommodated states. Then just as we did with the Le Grand eye, we use a linear
# accommodation formula to interpolate between the relaxed and fully accommodated states in the Emsley eye, using the focusing
# parameter fp.


# This version of the Emsley eye incorporates up to two corrective lenses in contact (as a doublet lens) at vertexDistance from the 
# front cornea:

emsleyEyeImageDistCorLens(objectDistance, powerCor1, powerCor2, w, fp) =                          \
    surfaceImageDist(0.006047249 - fp * 0.000652112, airN(w), waterN(w), vertexDistance -         \
    correctiveLens2ImageDist(powerCor2, w, 0 -                                                    \
    correctiveLens1ImageDist(powerCor1, w, objectDistance - vertexDistance)))


# If the variable "eyeModel" is set to 2, then we override the Le Grand eye model when plotting graphs in this script file, and 
# instead use the Emsley reduced eye model.
if(eyeModel==2) {

    eyeImageDist(objectDistance, w, fp) = emsleyEyeImageDist(objectDistance, w, fp) 

    eyeImageDistCorLens(objectDistance,powerCor1,powerCor2,w,fp) = emsleyEyeImageDistCorLens(objectDistance,powerCor1,powerCor2,w,fp)
}



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# autoFocus(objectDistance, w, eyeAxialLength, 0.5, 0.5)
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# Always call this function with the last two arguments set to 0.5 and 0.5 (they are used to prime the binary convergence).

# This function is an inverse of eyeImageDist(), as this function returns the precise value of fp necessary to focus light of 
# wavelength w from a point object at objectDistance away from the front corneal surface of the eye onto the retina (the retina is 
# located a distance of eyeAxialLength metres from the front corneal surface). The paraxial approximation is used for calculations.

# This autoFocus function uses a binary search to converge to the correct value for fp at which light of wavelength w is focused on the
# retina. By recursive calls to itself, the autoFocus() function gets closer and closer to the correct value for fp. 

# We start the binary search by setting fp = 0.5, and then calling the eyeImageDist(objectDistance, w, fp) function, and this 
# eyeImageDist() function then returns the image distance for that objectDistance. If this image distance is greater than the 
# eyeAxialLength, then we know we need to increase fp, so as to increase the eye's refractive power, and thus shorten the image focal
# length. 

# Conversely if the image distance returned by the call to eyeImageDist() is less than the eyeAxialLength, we know we need to decrease
# fp, so as to decrease the eye's refractive power, and thus increase the image distance. We keep adjusting fp like this until we get 
# an image distance equal to the eyeAxialLength, which then means the image is in focus on the retina. 

# To implement this automatic focusing via this binary search, we recursively call the autoFocus() function. On each recursive call, 
# we either decrease fpConverge by the amount 'jump' to shorten the image distance, or increase by amount jump to lengthen the image  
# distance, as appropriate. We reduce the jump value by a factor of 2 on each recursion to create smaller and smaller steps converging
# onto the correct value of fp. Once the value of jump is reduced to < 0.0000001, we exit the recursion and return the value of 
# fpConverge, which becomes the precise fp value that focuses the eye model.

# Note that the value of fp returned by this function is constrained to the range 0 to 1. 


autoFocus(objectDistance, w, eyeAxialLength, fpConverge, jump) = jump < 0.0000001 ?               \
    clamp(0, 1, fpConverge) :                                                                     \
    eyeImageDist(objectDistance, w, fpConverge) > eyeAxialLength ?                                \
    autoFocus(objectDistance, w, eyeAxialLength, fpConverge + jump, jump/2.0 ) :                  \
    autoFocus(objectDistance, w, eyeAxialLength, fpConverge - jump, jump/2.0 )


# The above autoFocus() definition has two nested ternary conditional (?:) operators that implement an equivalent nested IF statement  
# of the form:

# IF jump < 0.0000001 THEN  
#    exit recursion, returning the current value for fpConverge, using clamp(0, 1, fpConverge) to constrain this value from 0 to 1
# ELSE jump >= 0.0000001 
#    IF      eyeImageDist(fpConverge) > eyeAxialLength    THEN    recursively call autoFocus() with fpConverge increased 
#    ELSE IF eyeImageDist(fpConverge) < eyeAxialLength    THEN    recursively call autoFocus() with fpConverge decreased
#    END IF
# END IF

# Note: this autoFocus function could fail to converge to the correct value of fp if there were local maxima or minima in the function 
# eyeImageDist(objectDistance, w, fp) as fp varies, or if eyeImageDist() were not monotonic with respect to fp. However, the graph of 
# eyeImageDist(objectDistance, w, fp) versus fp has no local maxima or minima and is monotonic, as can be verified by plotting this 
# graph.

# Note: for an object stimulus with an accommodative demand of D dioptres, the value of focusing parameter fp that will focus that 
# stimulus is given by fp = autoFocus(1/D, w, eyeAxialLength, 0.5, 0.5). In this way, we can express dioptres of accommodative demand
# in terms of fp.



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# autoFocusLoA(objectDistance, eyeAxialLength, 0.5, 0.5)       This version of the autofocus() function includes lag of accommodation
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# Always call this function with the last two arguments set to 0.5 and 0.5 (they are used for the binary convergence).

# This function is identical to autoFocus() except that it incorporates lag of accommodation, whereby the eye brings into focus 
# increasingly shorter (bluer) wavelengths on the retina as accommodation increases.

# The degree of accommodation is indicated by fp, and the wavelength that gets focused on the retina is determined by the function
# focusWavelength(fp) which is used internally in this autoFocusLoA() function.

# During its autofocusing operation, this autoFocusLoA() function thus simulates the lag of accommodation found in real eyes.

autoFocusLoA(objectDistance, eyeAxialLength, fpConverge, jump) = jump < 0.0000001 ?               \
    clamp(0, 1, fpConverge) :                                                                     \
    eyeImageDist(objectDistance, focusWavelength(fpConverge), fpConverge) > eyeAxialLength ?      \
    autoFocusLoA(objectDistance, eyeAxialLength, fpConverge + jump, jump/2.0 ) :                  \
    autoFocusLoA(objectDistance, eyeAxialLength, fpConverge - jump, jump/2.0 )



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# autoFocusLoACorLens(objectDistance, powerCor1, powerCor2, eyeAxialLength, 0.5, 0.5)
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# Always call this function with the last two arguments set to 0.5 and 0.5 (they are used for the binary convergence).

# This function is identical to autoFocusLoA() except that one or two corrective lenses of dioptre power powerCor1 and powerCor2 are 
# placed in contact (as a doublet lens) in front of the eye, at vertexDistance away from the apex of the front corneal surface. In this 
# function, the object distance is still measured from the apex of the front surface of the cornea, not from the corrective lens.
# If only one corrective lens is required, this can be set in powerCor1, setting powerCor2 to 0. 

autoFocusLoACorLens(objectDistance, powerCor1, powerCor2, eyeAxialLength, fpConverge, jump) = jump < 0.0000001 ?                      \
    clamp(0, 1, fpConverge) :                                                                                                         \
    eyeImageDistCorLens(objectDistance, powerCor1, powerCor2, focusWavelength(fpConverge), fpConverge) > eyeAxialLength ?             \
    autoFocusLoACorLens(objectDistance,  powerCor1, powerCor2, eyeAxialLength, fpConverge + jump, jump/2.0 ) :                        \
    autoFocusLoACorLens(objectDistance,  powerCor1, powerCor2, eyeAxialLength, fpConverge - jump, jump/2.0 )



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# ametropicAxialLength(powerCor1, powerCor2)     
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# This function calculates the schematic eye axial length for a specified degree of axial myopia or hyperopia.

# Given the dioptre powers of the one or two corrective lenses placed in contact (as a doublet) in front of the eye at vertexDistance 
# from the apex of the front corneal surface, this function calculates the eye ametropic axial length that corresponds to the degree of  
# myopia or hyperopia the corrective lens or lenses imply. To calculate this ametropic axial length, we place a model corrective lens
# or lenses with the specified dioptre power (measured at the standardWavelength) in front of the relaxed schematic eye gazing at
# infinity, and calculate the focal length for light at the relaxed wavelength (which is the red wavelength the relaxed eye focuses on
# the retina when looking at infinity). The focal length is measured from the apex of the front corneal surface. This focal length is
# the eye axial length corresponding to the degree of myopia or hyperopia specified by the corrective lens or lenses. 

# The relaxed wavelength is slightly different for each of the ten Ivanoff subjects, and in this function, the relaxed wavelength used 
# depends on which Ivanoff subject is selected by the global variable 'person'. 

# If only one corrective lens is required, this can be set in powerCor1, setting powerCor2 to 0. 

ametropicAxialLength(powerCor1, powerCor2) = eyeImageDistCorLens(1e90, powerCor1, powerCor2, relaxedWavelength(0), 0)


# To base the myopic (or hyperopic) ametropic eye axial length calculation on the focal length of the corrective lens plus relaxed eye   
# at the standard wavelength, replace relaxedWavelength(0) with standardWavelength in the above function, giving the following:
# ametropicAxialLength(powerCor1, powerCor2) = eyeImageDistCorLens(1e90, powerCor1, powerCor2, standardWavelength, 0)




# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»
# BLUR FUNCTIONS AND VISUAL FEEDBACK SIGNAL FUNCTIONS
# The visual feedback signal is calculated from blur circle diameters for different wavelengths of light. In this section, we set up 
# blur() functions that calculate the blur circle sizes. These are then used to set up a visual feedback signal function VFSignal().
# We also define the function eyeAiryDiskDiameter() which is needed within the blur() function.
# »»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»»

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# eyeAiryDiskDiameter(fp, w) 
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# This function returns the eye's Airy disk diameter in metres for the specified light wavelength, and for the state of eye 
# accommodation given by fp (fp changes the focal length of the eye). The Airy disk diameter returned by this function also depends on 
# pupil size, which is set in the global variable pupilDiameter. This function is based on the formula:

# Airy disk diameter = 2.44λf/D

# Where: λ = wavelength, f = effective focal length of the lens, D = diameter of the lens. All measurements in metres.

# Blur circles cannot be smaller than the Airy disk, so we use this function to impose an Airy limit on blur circle minimum size in the
# blur() function defined below.

# The following details how we construct the Airy disk function used in this script:

# The total dioptre power for the Le Grand Full Theoretical Eye in the relaxed state is 59.9404 dioptres, and 67.6767 dioptres when 
# fully accommodated. This information comes from page 210 of the book: Günter Wyszecki, Walter Stanley Stiles. "Color Science Concepts 
# and Methods, Quantitative Data and Formulas". Wiley; 1967. The information is also found on page 66 of the book: Yves Le Grand and 
# Sami El Hage. "Physiological Optics". Springer-Verlag; 1980.

# Le Grand provides the total dioptre power of the relaxed Full Theoretical Eye at various wavelengths, given in the table below. This
# information comes from page 9 of his book: Yves Le Grand. "Form and Space Vision". Bloomington: Indiana University Press; 1967. 

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~      ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~
#                                  Colour:      Infrared          Red               Yellow            Blue              Violet
#                         Fraunhofer Line:      Oxygen A          Hydrogen C        Sodium D          Hydrogen F        Calcium G
#                              Wavelength:      759.4 nm          656.3 nm          589.3 nm          486.1 nm          430.8 nm
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~      ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~       ~~~~~~~~~~~
# Total eye power relaxed                       59.161            59.585            59.9404           60.771            61.442
# Total eye power accommodated                 [66.797]          [67.275]           67.6767          [68.6145]         [69.3721]

# However, these books do not provide the total dioptre power for the accommodated Full Theoretical Eye, except at the 589.3 nm 
# wavelength. So to estimate the accommodated eye total power for the above wavelengths, we use the formula: accommodated eye power = 
# relaxed eye power * (67.6767 / 59.9404) . Here we assume that multiplying the relaxed total power by the ratio of accommodated to 
# relaxed total powers at 589.3 nm, we can estimate figures for the accommodated eye total power at other wavelengths. The estimated 
# accommodated eye total power figures calculated by this method are shown above in square brackets [].

# Note that the effective focal length is 1 / (total power). So applying this formula to the above figures we have:

# Effective focal length relaxed                0.01690           0.01678           0.01668           0.01646           0.01628
# Effective focal length accommodated           0.01497           0.01486           0.01478           0.01457           0.01442

# Then using curve fitting at https://mycurvefit.com/ (employing a "quartic regression" curve), we create equations that give the  
# relaxed and fully accommodated effective focal lengths of the Le Grand schematic eye at any arbitrary wavelength w (in nanometres):

relaxedEFL(w)      = 0.008696458 + 0.00004178749*w - 8.636792e-8*w**2 + 8.338927e-11*w**3 - 3.079584e-14*w**4 
accommodatedEFL(w) = 0.017229160 - 0.00002984273*w + 9.693832e-8*w**2 - 1.233373e-10*w**3 + 5.567018e-14*w**4

# Thus the effective focal length of the Le Grand eye, at an arbitrary state of accommodation fp, and for any wavelength w, can be 
# calculated by the following linear formula: 

EFL(fp, w) = relaxedEFL(w) * (1-fp) + accommodatedEFL(w) * fp 

# Some effective focal lengths calculated by this EFL(fp, w) function:
# Blue cone peak sensitivity wavelength 437 nm, relaxed eye,     — Gives effective focal length = 16.30 mm
# Blue cone peak sensitivity wavelength 437 nm, accommodated eye — Gives effective focal length = 14.44 mm
# Red  cone peak sensitivity wavelength 564 nm, relaxed eye,     — Gives effective focal length = 16.64 mm
# Red  cone peak sensitivity wavelength 564 nm, accommodated eye — Gives effective focal length = 14.74 mm

# So finally we can write our Airy disk equation, as a function of both fp and the wavelength w:

eyeAiryDiskDiameter(fp, w) = 2.44 * (w * 0.000000001) * EFL(fp, w) / pupilDiameter

# This Airy disk equation also depends on the global variable pupilDiameter.

# Some Airy disk values calculated by this eyeAiryDiskDiameter(fp, w) function: 
# Blue cone peak sensitivity wavelength 437 nm, relaxed eye,      and pupil diameter 3 mm — Gives Airy disk diameter = 5.79 μm
# Blue cone peak sensitivity wavelength 437 nm, accommodated eye, and pupil diameter 3 mm — Gives Airy disk diameter = 5.13 μm
# Red  cone peak sensitivity wavelength 564 nm, relaxed eye,      and pupil diameter 3 mm — Gives Airy disk diameter = 7.63 μm
# Red  cone peak sensitivity wavelength 564 nm, accommodated eye, and pupil diameter 3 mm — Gives Airy disk diameter = 6.76 μm

# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# blur(objectDistance, w, blurPlaneOffset, eyeAxialLength)     
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# This function calculates the diameter (in metres) of the blur circle for light of wavelength w that is projected onto the retina by 
# a conceptual point object.

# When the blur() function is called, it automatically gets the eye model to autofocus the image of a point object onto the retina 
# (with lag of accommodation taken into account). The retina is located at a distance of eyeAxialLength from the apex of the front
# surface of the cornea. After the eye model focuses the image on the retina, the blur() function then calculates and returns the blur
# circle diameter cast onto the retina for light of wavelength w. This calculation is detailed in the geometric construction below. 

# Note that blur circles can never be smaller than the Airy disk, so we set a minimum blur circle size within the blur() function, such
# that this function will not return a blur circle diameter smaller than the Airy disk diameter for the eye.  
#
# THE FOLLOWING DESCRIBES THE GEOMETRIC CONSTRUCTION WE USE TO CALCULATE BLUR CIRCLE SIZES

# Let eyeImageDistance be our image distance, with respect to the apex of the front surface of the cornea.
#
#           retina      
#   pupil     |         Let the pupil diameter be p, the blur circle diameter on the retina be q, the pupil-to-image point distance 
#     |\      |         be a, and the image point-to-retina distance be b, then we have:
#     | \     |       
#     |  \  /||                        q/p  =  b/a,   so, blur circle diameter q = p * b / a
#     |p  \/q||
#     |   /\ ||         In the eye, the pupil (iris aperture) is positioned about 3 mm into the eye (from the front of the cornea), so:
#     |  /  \|| 
#     | /     |                        a    =  (eyeImageDistance - 0.003)
#     |/      |                        b    =  (eyeAxialLength - eyeImageDistance)
#             |                           
#                       Thus the blur circle diameter q is given by:
#     | a  |b |
#                       q   =   p *       (eyeAxialLength - eyeImageDistance)                        /  (eyeImageDistance - 0.003)
#                           =   p *     ( (eyeAxialLength - 0.003)  -  (eyeImageDistance - 0.003) )  /  (eyeImageDistance - 0.003)
#                           =   p *     ( (eyeAxialLength - 0.003)  /  (eyeImageDistance - 0.003)  - 1 )
#
# We need to take the absolute value of the expression for q, for the case when b is negative (image point right of retina).

# Based on the above, the following function calculates the blur circle diameter (in metres) for light of wavelength w, with the eye  
# model in autofocus mode:

blur(objectDistance, w, blurPlaneOffset, eyeAxialLength) =                                                                            \
                                                                                                                                      \
max(eyeAiryDiskDiameter(autoFocusLoA(objectDistance, eyeAxialLength, 0.5, 0.5), w),                                                   \
                                                                                                                                      \
    1.0 * pupilDiameter * abs( -1 + (blurPlaneOffset + eyeAxialLength - 0.003)    /                                                   \
     (eyeImageDist(objectDistance, w, autoFocusLoA(objectDistance, eyeAxialLength, 0.5, 0.5)) - 0.003) )                             \
)



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# A note on calculating the blur circle diameter on the peripheral retina in a myopic schematic eye using the blur() function.
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

# Uneven eye growth often occurs in myopia, creating an oval-shaped eye that is longer along its optical axis than in other dimensions.
# As a result, when myopes wear corrective lenses that focus the image on their fovea, at the retinal periphery, there may be hyperopic
# defocus, meaning the image is focused behind the retina. In order to calculate the blur circle diameter at the retinal periphery of
# myopes, we have added a special feature to the blur() function, which is as follows. 

# Normally, the blur() function calculates blur circle size by first adjusting the schematic eye lens to focus the image on the  
# posterior pole of the retina (taking into account lag of accommodation), and then for the specified wavelength, calculating the blur  
# circle diameter on the posterior pole. In emmetropes, this calculated blur circle diameter is also valid at the retinal periphery, up
# to an angle of 20° from the optical axis (since the paraxial approximation used in our eye model is valid for angles up to 20°). But
# the retinal periphery of myopes lie closer to the eye lens than the posterior pole, so when the image is in focus on the posterior
# pole, the image does not come into focus on the peripheral retina, but behind it. Thus the posterior pole blur circle size
# calculation is not valid in the retinal periphery of myopes. 

# In order to adapt the blur() function to operate at the retinal periphery of myopes, we introduce a variable blurPlaneOffset to 
# blur(). Setting blurPlaneOffset to a non-zero distance (in metres) gets this function to calculate the blur circle diameter cast on 
# a plane shifted from the posterior pole by a distance of blurPlaneOffset, while still focusing the image on the posterior pole.  
# Positive values of blurPlaneOffset move this plane further from the cornea, and negative values shift the plane closer to the cornea.

# We then use data from real eyes to set blurPlaneOffset to the empirically measured distance between the myopic peripheral retina and 
# the point behind the peripheral retina where the image comes into focus. This allows us to calculate blur circle size on the 
# peripheral retina in a myopic schematic eye, as the plane acts as the surface of the peripheral retina. We determine the value of 
# blurPlaneOffset from empirical data as follows.

# This study: https://doi.org/10.21516/2072-0076-2018-11-4-36-41 examines a cohort of myopes aged 10 to 18 whose degree of myopia was
# -5.3 D on average. These myopes were found to have relative hyperopic defocus across their peripheral retina. At 15° to the visual 
# axis (15° retinal eccentricity), the relative hyperopic defocus was 0.52 dioptres on the temple side, and 0.51 dioptres on the nasal 
# side, an average of 0.52 dioptres. Note that the visual axis terminates at the fovea, and is displaced by around 5° from the optical 
# axis which terminates at the posterior pole. 

# The level of peripheral hyperopic defocus increases with greater angles of retinal eccentricity, but for the purposes of our model, 
# we assume that the relative hyperopic defocus at 15° to the visual axis roughly represents the average hyperopic defocus across all
# peripheral retinal eccentricity angles in the myopic eye where emmetropisation takes place. 

# In our Le Grand model, 0.52 D of hyperopia corresponds to a 0.19 mm shift in image point position. This is calculated using the
# function eyeImageDistSingleCorLens(objectDistance, powerCor, w, fp), with objectDistance = 1e90, w = standardWavelength, fp = 0 and
# noting the difference in calculated focal length as powerCor is changed from zero to 0.52 dioptres. Thus if -5.3 D of myopia results
# in a 0.19 mm shift, -1 D of myopia will result in a 0.036 mm shift of focal point position behind the peripheral retina.

# So when we use our Le Grand model to simulate a myopic eye with an oval shape, and we want to calculate the blur circle size on the 
# peripheral retina, we set blurPlaneOffset to 0.000036 metres for each dioptre of myopia of the eye. For example, in an eye with -3 D 
# of myopia, we set blurPlaneOffset to 3 x 0.000036 = 0.000108 metres, in order to calculate the blur circle size on the peripheral   
# retina. But for calculating the blur circle size on the posterior pole of a myopic eye, blurPlaneOffset should be set to zero. And 
# for an emmetropic eye, blurPlaneOffset should be set to zero for calculating the blur circle size at both the posterior pole and at 
# the retinal periphery, because there is no hyperopic defocus in the periphery of emmetropic eyes.

offsetPerDioptre = 0.000036        # Offset of the blur circle plane (in metres) for each dioptre of myopia of the eye 



# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# blurCorLens(objectDistance, powerCor1, powerCor2, w, blurPlaneOffset, eyeAxialLength)   
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# This function calculates the diameter (in metres) of the blur circle created on the schematic retina by a point object.

# This version of the blur function includes up to two corrective lenses placed in contact (as a doublet lens) in front of the  
# schematic eye, at vertexDistance from the apex of the front surface of the cornea. The dioptre powers of these two corrective lenses 
# are set by powerCor1 and powerCor2.

blurCorLens(objectDistance, powerCor1, powerCor2, w, blurPlaneOffset, eyeAxialLength) =                                                                \
                                                                                                                                                       \
max(eyeAiryDiskDiameter(autoFocusLoACorLens(objectDistance,powerCor1,powerCor2,eyeAxialLength,0.5,0.5), w),                                            \
                                                                                                                                                       \
1.0 * pupilDiameter * abs( -1 + (blurPlaneOffset + eyeAxialLength - 0.003)    /                                                                        \
(eyeImageDistCorLens(objectDistance,powerCor1,powerCor2,w,autoFocusLoACorLens(objectDistance,powerCor1,powerCor2,eyeAxialLength,0.5,0.5)) - 0.003) )   \
)



# For convenience of notation, we define three blur circle functions at the blue, green and red cone peak sensitivity wavelengths:

Blue(objectDistance,  powerCor1, powerCor2, blurPlaneOffset, eyeAxialLength) = \
    blurCorLens(objectDistance, powerCor1, powerCor2, blueConeW,  blurPlaneOffset, eyeAxialLength) + blueBlurCircleAddition

Green(objectDistance, powerCor1, powerCor2, blurPlaneOffset, eyeAxialLength) = \
    blurCorLens(objectDistance, powerCor1, powerCor2, greenConeW, blurPlaneOffset, eyeAxialLength)

Red(objectDistance,   powerCor1, powerCor2, blurPlaneOffset, eyeAxialLength) = \
    blurCorLens(objectDistance, powerCor1, powerCor2, redConeW,   blurPlaneOffset, eyeAxialLength)


# blueBlurCircleAddition is used to simulate the effect of viewing a video screen image in which the blue RGB channel has been 
# slightly blurred. Normally blueBlurCircleAddition is set to zero, unless simulating blue channel blur.


# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# VFSignal(objectDistance, powerCor1, powerCor2, blurPlaneOffset, eyeAxialLength)     
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
# This function calculates the visual feedback signal. If the global variable 'formula' is set to 1, the visual feedback signal is  
# calculated as the difference B-R of blue and red blur circle diameters. 

# This function calculates the visual feedback signal using an autofocus schematic eye. For any values of objectDistance and 
# eyeAxialLength within normal range, the autofocus eye accommodation mechanism automatically focuses the image onto the schematic 
# retina, taking into account lag of accommodation, meaning the wavelength it focuses on the retina depends on the degree of 
# accommodation. Once focus is achieved, the blur circle visual feedback signal is calculated and returned by this function. For 
# example, in the case of a B-R visual feedback formula, we have: VFSignal() = B-R, which translates to:

# VFSignal(objectDistance, powerCor1, powerCor2, blurPlaneOffset, eyeAxialLength) =
#     blurCorLens(objectDistance, powerCor1, powerCor2, blueConeW,  blurPlaneOffset, eyeAxialLength) - 
#     blurCorLens(objectDistance, powerCor1, powerCor2, redConeW,   blurPlaneOffset, eyeAxialLength)

# Up to two corrective lenses in contact (as a doublet) can be placed in front of the schematic eye by setting powerCor1 and powerCor2  
# to the desired dioptric power; if these are set to zero, then this is equivalent to not including any corrective lens.

# Below we define several different versions of VFSignal() to represent different visual feedback signal formulas.
# Abbreviated function arguments: o = objectDistance, p = powerCor1, q = powerCor2, r = blurPlaneOffset, l = eyeAxialLength.

# The global variable 'formula' selects the visual feedback formula we use, formulas such as B-R, B-(G+R)/2 and (B-R)*(B+R). 

VFSignal(o,p,q,r,l) = (formula == 1)  ?  (Blue(o,p,q,r,l)  - Red(o,p,q,r,l)  ) * 10**6  :                                             \
                      (formula == 2)  ?  (Blue(o,p,q,r,l)  - Green(o,p,q,r,l)) * 10**6  :                                             \
                      (formula == 3)  ?  (Green(o,p,q,r,l) - Red(o,p,q,r,l)  ) * 10**6  :                                             \
                      (formula == 4)  ?  (Blue(o,p,q,r,l)  - (Green(o,p,q,r,l) + Red(o,p,q,r,l))/2) * 10**6  :                        \
                      (formula == 5)  ?  Blue(o,p,q,r,l)   / Red(o,p,q,r,l)             :                                             \
                      (formula == 6)  ?  Blue(o,p,q,r,l)   / Green(o,p,q,r,l)           :                                             \
                      (formula == 7)  ?  Green(o,p,q,r,l)  / Red(o,p,q,r,l)             :                                             \
                      (formula == 8)  ?  (Blue(o,p,q,r,l)  - Red(o,p,q,r,l)) / (Blue(o,p,q,r,l) + Red(o,p,q,r,l))  :                  \
                                         (Blue(o,p,q,r,l)  - Red(o,p,q,r,l)) * (Blue(o,p,q,r,l) + Red(o,p,q,r,l)) * 10**12
                                              
                                              
# Set formula = 1 for a B-R visual feedback formula, set formula = 4 for B-(G+R)/2, formula = 5 for B/R, formula = 8 for (B-R)/(B+R),
# set formula = 9 for a (B-R)*(B+R) formula


# The 10**6 multiplier expresses B-R in terms of micrometres rather than metres (whereas the B/R and the (B-R)/(B+R) formulas are 
# dimensionless). The 10**12 multiplier expresses (B-R)*(B+R) in terms of micrometres squared.


# The formulaString text strings below are displayed in the graph y axis label.

if(formula==1) formulaString = "B−R (μm)"   
if(formula==2) formulaString = "B−G (μm)"
if(formula==3) formulaString = "G−R (μm)"
if(formula==4) formulaString = "B-(G+R)/2 (μm)"
if(formula==5) formulaString = "B/R"
if(formula==6) formulaString = "B/G"
if(formula==7) formulaString = "G/R"
if(formula==8) formulaString = "(B−R)/(B+R)"
if(formula==9) formulaString = "(B−R)×(B+R) (μm^2)"

# EYE ACCOMMODATION (fp) VERSUS OBJECT DISTANCE (m)
# This graph is to test the autoFocus() and autoFocusLoA() functions.

# The autoFocus() function does not take into account lag of accommodation, meaning it does not make use of focusWavelength(fp). In  
# this graph, autoFocus() calculates the value of fp required to focus light of the relaxed wavelength onto the retina as the object
# distance is varied. The relaxed wavelength = the Ivanoff subject's wavelength in focus when they look at infinity (this relaxed 
# wavelength is in the red part of the spectrum, but is slightly different for each Ivanoff subject).

# By contrast the autoFocusLoA() function takes lag of accommodation into account, and employs the function focusWavelength(fp). For a 
# given object distance, autoFocusLoA() calculates the value of fp such that the eye model focuses light of a wavelength given by 
# focusWavelength(fp) onto the retina. 

# We find that the autoFocusLoA() curve minimises the variation of fp as the object distance varies, compared to the autoFocus() curve.
# Minimising the variation of fp is what Yves Le Grand termed the principle of least effort of accommodation (now called the lag of 
# accommodation).
# ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
if(GTP==25) {

set xlabel "Object Distance (metres)" offset 0, 0.2

set xrange [0 :  5]; set xtics 1; set mxtics 10       # Object distance (metres)
set yrange [0 :  1]; set ytics 0.1                    # Accommodation (fp)


plot \
autoFocus(x, relaxedWavelength(0), emmetropicAxialLength(0), 0.5, 0.5) title sprintf("Fixed Wavelength Focusing (at %i nm)", relaxedWavelength(0))  lc rgb "red" , \
autoFocusLoA(x, emmetropicAxialLength(0), 0.5, 0.5) title "Focusing With Lag of Accommodation"  lc rgb "blue" lw 1.5
