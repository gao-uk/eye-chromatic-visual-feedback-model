# eye-chromatic-visual-feedback-model
A gnuplot script modelling a human eye visual feedback mechanism operating on longitudinal chromatic aberration that regulates eye axial length (emmetropisation). 

This repository contains a gnuplot script file that runs on the free gnuplot graphing application, available here: http://www.gnuplot.info 

The gnuplot script file plots a series of graphs illustrating the characteristics of a mathematically-modelled schematic human eye visual feedback mechanism (VFM). This VFM regulates the schematic eye axial length (ie, achieves emmetropisation) by measuring the levels of blue and red image blur on the schematic eye retina which arise from ocular longitudinal chromatic aberration.

This gnuplot script file accompanies a 2026 study entitled "A Software Model of Chromatic Aberration Visual Feedback in the Eye: Exploring the Role of Near Work in Myopia Development" by G. A. Olmi.
