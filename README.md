**Hypothesised Eye Visual Feedback Mechanism Modelling Emmetropisation Driven by Ocular Longitudinal Chromatic Aberration: For the Purpose of Exploring How Sustained Near Work May Induce Myopia**

This repository contains a script file which runs in the free gnuplot graphing application, and plots a series of graphs. 

This gnuplot script encodes a software eye model comprising the Full Theoretical Eye of Yves Le Grand linked to a hypothesised visual feedback mechanism (VFM) that takes its cues from ocular longitudinal chromatic aberration to accomplish emmetropisation (regulation of eye axial length). 

The VFM operates by measuring the levels of blue and red image blur on the Le Grand schematic eye retina, and from these calculating a visual feedback signal that regulates eye axial length.

This schematic eye model and its associated VFM are used to explore how prolonged near work may induce myopia.

This gnuplot script file accompanies a 2026 study entitled "A Software Model of Chromatic Aberration Visual Feedback in the Eye: Exploring the Role of Near Work in Myopia Development" by G. A. Olmi.

The free gnuplot graphing app is available for Microsoft Windows, macOS, Linux and Unix. See: http://www.gnuplot.info
